# comments

Inventory and strip code comments, proving every strip is semantics-free.

A reader decides WHICH comments earn their place (cheap — a list of line
numbers); this tool owns the cutting and the proof. `list` emits one compact
line per comment so the decision needs no file reads; `strip` removes exactly
the lines named and reverts any file whose normal form moves.

Supported: Python, shell, Nix, TypeScript/JavaScript, C#, Rust, CSS, HTML,
SQL, protobuf, YAML, TOML.

## The gate

For every file: normalise, edit, normalise again. Each language's normaliser
discards comments and preserves everything else, so an identical normal form
before and after proves the edit removed comments and nothing else. A file
that stops parsing, or whose normal form moves, is restored and reported — a
bad strip cannot reach the tree.

| ext | normal form | why it proves the strip is safe |
|---|---|---|
| `.py` | `ast.dump(ast.parse(...))` | comments aren't AST nodes |
| `.sh` | `shfmt -mn` | minified, comments dropped; here-doc bodies kept verbatim |
| `.nix` | `nix-instantiate --parse` | comments discarded at parse |
| `.ts .tsx .js .jsx .mjs .cjs` | TypeScript scanner token stream | comments are trivia, never tokens |
| `.cs` | own scanner → code/string/preprocessor record stream | no C# parser available; scanner proves its own inventory |
| `.rs` | own scanner, whitespace collapsed to one space | doc comments are `#[doc]` attrs, kept verbatim |
| `.yml .yaml` | `safe_load_all` → sorted JSON | comments aren't data |

A **REVERTED** file is a language-module bug, not an acceptable loss. Diff it
and fix the module. Exit is non-zero if anything reverted.

## Usage

```sh
comments list [PATH...]                  # path:line:col: text — read this, decide
comments strip FILE:LINE[,LINE...] ...   # cut exactly those, proved safe
comments strip --all [PATH...]           # the zero-comment sweep
```

`comments-list` and `comments-strip` are shorthands for the two subcommands.

`list` prints one line per comment and nothing else, so a whole directory's
comments cost a few hundred tokens to review — no file reads. `--all` also
shows KEEP-protected directives, marked; `--json` for programmatic use.

`strip` removes only the comments **starting** on the lines you name, so a
multi-line block comment needs just its first line. Unnamed comments are left
alone, and a line with no comment on it is a no-op rather than an error.
`--check` reports without writing, in either mode. `--collapse-blanks` also
closes a blank run left behind by a removal — never inside a string, here-doc,
or block-scalar body.

With nix:

```sh
nix run github:eordano/strip-comments -- list src/
```

## What it refuses to strip

Each language module has a `KEEP` pattern for comments that are **directives,
not prose** — removing them changes behaviour or tooling results. `# noqa`,
`# type:`, `# shellcheck`, `# yamllint disable`, `@ts-expect-error`,
`eslint-disable`, `prettier-ignore`, `#__PURE__`, `sourceMappingURL`,
`@license`/SPDX, `yaml-language-server:`, shebangs, coding declarations, and
more. In C# that also covers `///` and `/**` XML doc comments (compiled
output, not commentary) plus `// <auto-generated/>` and `// ReSharper
disable`. In Rust it covers all four doc-comment forms (`///` `//!` `/**`
`/*!` — they desugar to `#[doc]`, and can contain a doctest `cargo test`
runs) plus `//~ ERROR`, `//@` and `// SAFETY:`.
`strip` will not remove them even if you name their line; `list --all` shows
them marked so you can see what was skipped.

## Proving a module: `selftest`

The gate proves one edit. It cannot prove the *scanner*, since the scanner
also produces the normal form — a mis-framing identical before and after
passes. `selftest` attacks the module instead of the edit; run it against a
real corpus after any module change:

```sh
comments selftest .                       # every language with files here
comments selftest . --lang .rs --files 8 --mutations 8
```

Three checks: **coords** (every reported `(line, col)` must land on the
reported text in the driver's frame), **keep** (every KEEP branch must
actually fire against the corpus), and **gate** (mutate non-comment,
non-whitespace bytes; the normal form must move or raise — any `BLIND` count
is a normal form too lossy to be a proof).

## Runtime dependencies

Python 3.11+ with PyYAML. Per language, resolved at runtime: `.sh` needs
`shfmt` (bundled in the nix package), `.nix` needs `nix-instantiate`, and
`.ts`/`.js` need `node` plus a `typescript` package resolvable upward from
the file's own directory — with none reachable, those files are skipped
rather than stripped unproven.

## Adding a language

Drop a module in `lang/`. The driver owns all excision; a module only
supplies knowledge:

```python
EXTS: tuple[str, ...]
KEEP: re.Pattern | None
def comments(src) -> list[tuple[line, col_start, col_end, text]]   # 1-based line, 0-based cols
def protected_lines(src) -> set[int]        # lines whose blankness is content
def normalize(path) -> str                  # comment-free normal form; RAISE if unparseable
```

For a multi-line comment, `line` is its first line and `col_end` its end
column on its last; the driver derives the last line as
`line + text.count('\n')`. `normalize` must never fall back to a weaker form
— a file that cannot be proved is a file that does not get stripped.

## History

This repository previously held a lexer-only stripper (two comment grammars,
no proof of safety). This tool supersedes it: per-language scanners, a
semantics-equality gate on every edit, and a selftest that attacks the
scanners themselves.
